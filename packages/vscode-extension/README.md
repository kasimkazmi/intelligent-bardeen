# superpowers-vscode-extension

This package contains the VS Code integration. It contributes:
1.  **Sidebar Webview Dashboard:** A React-based interface showing the active workflow, checkboxes, progress bars, and terminal outputs.
2.  **Native Chat Participant:** A `@superpowers` participant inside GitHub Copilot Chat for slash commands (`/brainstorm`, `/tdd`, `/debug`) and custom interactive buttons.
